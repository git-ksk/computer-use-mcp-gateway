# Support

> この日本語版は [`SUPPORT.md`](SUPPORT.md) の翻訳です。**英語版を canonical（正典）とし、解釈に差がある場合は英語版を優先します。**

CUMG は best-effort で保守され、commercial support SLA は提供しません。

repository の issue form は次に使用してください。

- reproducible な CUMG bug;
- documentation defect;
- project boundary に収まる scoped feature proposal;
- [`docs/GETTING_STARTED.ja.md`](docs/GETTING_STARTED.ja.md) と [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md) を確認した後の usage/setup question。

bug を報告する前に、practical なら supported CUMG version で再現し、可能な範囲で CUMG behavior と upstream Cua Driver behavior を切り分けてください。

**security vulnerability を public support / bug issue として投稿してはいけません。** [`SECURITY.ja.md`](SECURITY.ja.md) に従い、GitHub Private Vulnerability Reporting を使用してください。

feature proposal では [`docs/ROADMAP.ja.md`](docs/ROADMAP.ja.md)、[`docs/PROJECT_GOVERNANCE.ja.md`](docs/PROJECT_GOVERNANCE.ja.md)、V2 product boundary の [`docs/v2/V2_POSITIONING.ja.md`](docs/v2/V2_POSITIONING.ja.md) を確認してください。技術的に可能であることだけでは project scope に入りません。

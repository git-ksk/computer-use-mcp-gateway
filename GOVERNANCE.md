# Governance

> English is canonical. [日本語版 / Japanese translation](GOVERNANCE.ja.md)

The canonical CUMG governance policy is [`docs/PROJECT_GOVERNANCE.md`](docs/PROJECT_GOVERNANCE.md).

It defines maintainer authority, change classes, review and merge gates, documentation localization rules, dependency/upstream review, feature admission, and release decision responsibilities. Version selection and release mechanics are defined separately in [`docs/VERSIONING.md`](docs/VERSIONING.md).

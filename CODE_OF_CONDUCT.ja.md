# Code of Conduct

> この日本語版は [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) の翻訳です。**英語版を canonical（正典）とし、解釈に差がある場合は英語版を優先します。**

CUMG は technical rigor と good-faith participation を重視します。この code は repository issue、pull request、review、project に関する discussion、および project-managed collaboration space に適用します。

## 期待する behavior

participant は次を守ってください。

- technical claim は evidence に基づいて議論し、fact と assumption を区別する;
- 人ではなく code、design、decision を批評する;
- coordinated disclosure が適切な security-sensitive detail を public thread に出さない;
- privacy を尊重し、credential、private endpoint、personal data、無関係な desktop content を投稿しない;
- project scope を尊重し、documented `NO-GO` decision への disagreement を harassment に変えない;
- technical / project decision に実質的な影響がある conflict of interest は開示する;
- contributor-facing documentation と issue context を正確に保つ。

## 許容しない behavior

次は許容しません。

- harassment、threat、discriminatory attack、targeted personal insult;
- doxxing、または許可なく第三者の private information を公開すること;
- sexualized harassment / unwanted sexual attention;
- credential、private vulnerability detail、sensitive user/desktop data を意図的に露出すること;
- sustained disruption、spam、impersonation、または訂正後も knowingly misleading な technical claim を続けること;
- good-faith な bug、security、review、moderation report への retaliation。

## Reporting と enforcement

public に安全に扱える通常の repository moderation concern は、GitHub の built-in reporting/moderation tool で該当 issue、comment、pull-request content を報告し、評価に必要な context だけを提供してください。

sensitive conduct concern では、新しい public issue に personal / confidential detail を投稿しないでください。必要に応じて GitHub platform の reporting/abuse mechanism を使用してください。security vulnerability は [`SECURITY.ja.md`](SECURITY.ja.md) の private process を使用します。

project safety と productive collaboration を守るため、maintainer は content の edit/removal、discussion の lock/limit、issue/PR の close、participation の block を行う場合があります。enforcement は technical disagreement そのものではなく、behavior、context、recurrence、impact に応じて proportionate に判断します。

## Project decision

maintainer authority と technical decision rule は [`docs/PROJECT_GOVERNANCE.ja.md`](docs/PROJECT_GOVERNANCE.ja.md) に定義します。この Code of Conduct は participation behavior を扱うものであり、scope / architecture に関するあらゆる disagreement を conduct matter にするものではありません。
